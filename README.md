# FIXWELL SERVICES INDIA — Admin Dashboard

Version 1 is a browser-based prototype for internal lead, quotation, project and payment tracking.

## Run locally
Open `index.html` in a modern browser.

## Important limitations
- This version stores records in the current browser using localStorage. It does not sync across devices.
- No authentication or server-side database is included yet.
- WhatsApp, AI prospecting, email, payment gateway, automatic follow-ups and notifications are not connected.
- Quotation approval is an internal status only; nothing is sent to a customer.
- Payment records must be verified manually against the bank/payment provider.

Do not enter passwords, OTPs, card details, bank credentials or sensitive customer data.
